# Biblioteca

Aplicación del taller de recuperación de navegación con Expo Router.

Incluye:

- Stack raíz
- Slot para el acceso
- Drawer con Inicio y Ajustes
- Tabs de Inicio, Favoritos y Perfil
- Lista y detalle de libros
- Modal Acerca de
- Entrada y cierre de sesión

## Ejecutar

```bash
npm install
npm run android
```

## Verificar

```bash
npm run lint
npx tsc --noEmit
npx expo-doctor
```

El PDF resuelto está en `output/pdf/Taller_Recuperacion_Navegacion_Resuelto.pdf`.
